# Retail Sales Analysis

End-to-end data analysis project covering data cleaning, SQL querying, Python EDA, and Power BI dashboarding on a retail sales dataset (2,000 orders).

## Tools Used
- *Excel* – initial data inspection
- *SQL (SQLite)* – querying and aggregation
- *Python (pandas, matplotlib, seaborn)* – exploratory data analysis
- *Power BI* – interactive dashboard

## Project Workflow
1. *Data Cleaning* – handled missing values, removed duplicates, fixed inconsistent text casing and mixed date formats
2. *SQL Analysis* – wrote queries for region-wise sales, category profit margins, monthly trends, and discount impact on profit
3. *Python EDA* – analyzed distributions, correlations, and visualized key patterns
4. *Power BI Dashboard* – built an interactive dashboard with KPI cards, category/region breakdowns, monthly trend, and discount-profit analysis

## Key Insights
- Profit drops sharply as discount increases — orders with discounts above 30% often result in losses
- Office Supplies generated the highest total sales among the three categories
- Sales show clear monthly fluctuations, useful for identifying seasonal patterns

## Files in this Repository
- retail_sales_raw.csv – original (messy) dataset
- retail_sales_clean.csv – cleaned dataset
- queries.sql / Reatai Sales Analysis.sqbpro – SQL queries
- retail_Sales_-checkpoint.ipynb – Python EDA notebook
- Retail_Sales_Dashboard.pbix – Power BI dashboard file
